# Squadra demo project

An empty project with three personas (in `.claude/skills/`) to try a squad:

1. **+ New session**, folder `/squadra/projects/demo`, role *Coordinator*, persona `project-lead`.
2. From the squad (👥), **+ Worker** twice: one with the persona `developer`, one with `designer`.
3. Ask the coordinator, in its terminal, for something small: "a web page with a to-do list".

Each persona is a plain skill: edit them, or add your own next to them.
