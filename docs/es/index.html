Claude Code multiagente,
con un coordinador y un panel en directo

Squadra dirige escuadras de agentes de Claude Code en cualquiera de tus equipos. Un agente coordinador reparte el trabajo, aprueba las acciones seguras y solo te pregunta lo importante. Tú lo ves todo en directo en el navegador.

Empezar en GitHub Leer la referencia In English

Qué puedes hacer con él

Una funcionalidad en varios repositorios a la vez

Backend, web y app móvil, cada uno con su worker, coordinados entre sí.

Partir un trabajo grande en paralelo

Una migración, una refactorización o más tests: un worker de Claude Code por módulo, todos a la vez.

Dejarlo trabajando solo

Los workers deciden los detalles técnicos; el coordinador aprueba sus acciones seguras y solo te escala lo crítico.

Vigilarlo desde cualquier sitio

Todos los agentes en directo en tu navegador, una terminal web a cada uno y una barra «Te necesitan» con quien espera.

Usar todos tus equipos y cuentas

Cada agente funciona en cualquier máquina que añadas, con la sesión de Claude Code de esa máquina. Los agentes conectan hacia fuera; sin abrir puertos.

Autoalojado, sin dependencias

Un servidor Node.js, o una imagen Docker. HTTPS automático cuando le das un dominio. Licencia MIT.

Squadra no sustituye a Claude Code: cada agente es un claude interactivo normal, así que puedes entrar y escribir en cualquiera en cualquier momento.

Instalación en dos pasos

git clone https://github.com/roke22/Squadra.git squadra && cd squadra
node server/server.js        # panel en http://127.0.0.1:7787

Después abre Máquinas → Añadir máquina en el panel y ejecuta el comando que te muestra en cada equipo donde quieras agentes. Las instrucciones completas, Docker y HTTPS están en el README en español.

Qué necesitas

  • Una cuenta de Claude Code: un plan de claude.ai (Pro, Max, Team o Enterprise) o una clave de API de Anthropic Console.
  • Un equipo para el panel con Node.js 22 o Docker. Puede ser el mismo donde trabajan tus agentes.
